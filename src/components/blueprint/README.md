# Blueprint UI primitives

Reusable presentation components for the mobile blueprint. Data fetching and
business logic remain in services/hooks so mobile and TV share one implementation.

- Rail: horizontally scrolling content row.
- MediaCard: poster/card with optional progress and focus behavior.
- HeroBanner: featured For You item.
- ActionButton: primary/secondary action button.
- Chip: metadata, category, or filter chip.
- SectionHeader: rail title and optional action.
- ProgressBar: continue-watching progress indicator.
- FocusCard: focusable wrapper for TV D-pad navigation.
