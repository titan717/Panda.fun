Install in four steps

From download to first episode.

  1. 1
    Download the APK

    Tap Download APK on your phone. On Android TV, open this page in a browser app on the TV, or copy the file over with a file manager or USB drive.

  2. 2
    Open the file

    Open it from your notifications, Downloads or file manager.

  3. 3
    Allow this one app to install

    If Android asks, allow installs only for the browser or file manager you used. You can switch that permission off again after installing.

  4. 4
    Install and open

    Tap Install, then open panda.fun and pick who's watching. Future updates arrive from Settings.
