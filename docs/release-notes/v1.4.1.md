# Panda.fun v1.4.1

Signed release build for Android phones, tablets and Android TV.

## What's new in 1.4.1

- **The TV keyboard opens from Search**: pressing OK on the Search field in the TV layout now opens the Android TV keyboard (Gboard) reliably. Before, the field changed to a text field a moment after the key press and the app asked for the keyboard too early, so on many TVs nothing appeared (the phone layout on the same TV was not affected). The field now switches inside the OK press itself, the app asks again until the keyboard is really on screen, and pressing Search on the keyboard runs the search and closes it.
- **A redesigned TV Search**: a larger rounded search bar with the microphone and Clear buttons lined up beside it, a clear "OK to type" hint while the field is focused, and a bright brand-coloured outline while you are typing. The discovery rows now start on the same left edge as the bar (they were indented twice), run to the edge of the screen instead of being cut off, and use the same poster size as the results.
- **Brand focus across the TV app**: the focus ring and glow on cards, buttons, tabs, seasons and episodes were a silver-blue left over from an older palette; they now use the Panda.fun purple and magenta. High contrast mode keeps its yellow ring.
- **TV polish**: Categories brings the first row closer to the title, My Space shows the profile and its actions on one card with rounded buttons, and focused buttons light up in the brand gradient. The phone layout is unchanged.

Testing for this release was done with unit and component tests, in desktop Chromium with the TV layout (1920 × 1080) and remote-key simulation, and on Android emulators (Android TV and phone, API 34) where pressing OK on the TV Search field was checked to open the system keyboard. It was not checked on a physical Android TV; please confirm Gboard opens on your TV.
